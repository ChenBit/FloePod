# 浮匣 FloePod 实施计划

本地优先、零联网、零 AI 的 Windows 屏幕边缘文件暂存工具。技术栈：Tauri 2 (Rust) + Vue 3 + TypeScript + Tailwind v4 + SQLite。最终交付 **x64 免安装便携版**。

## 第 0 步：前置准备
- 校验/安装工具链：Rust (MSVC x86_64)、Node ≥20、pnpm、WebView2 运行时（计划模式下未能探测，实施第一步完成）。
- **图标**：工作区内未找到 FloePod 图标。实施开始时向你要图标文件（png/svg ≥512px 均可）；若暂未提供，先用自绘几何占位图标，后续 `pnpm tauri icon <图>` 一条命令替换重打包，不阻塞交付。
- `git init` 本地仓库，按里程碑提交。

## 1. 窗口架构（Tauri 2 多窗口）
三个 WebviewWindow，共享一个 Vue 应用（hash 路由 `/bar` `/panel` `/settings`）：

| 窗口 | 角色 | 关键属性 |
|---|---|---|
| **bar** 常驻 | 浮动条/浮动书签（同一窗口，按设置渲染两种形态） | 无边框、透明、置顶、跳过任务栏、原生 drag-drop 开 |
| **panel** 弹出面板 | 暂存文件列表（主菜单） | 预建隐藏，悬停/点击时以 `SW_SHOWNOACTIVATE` 显示（不抢焦点）、`dragDropEnabled: false` |
| **settings** | 设置窗口 | 标准窗口、按需创建 |

关键工程决策：
- **bar 窗口物理尺寸固定且大于可视条**（如左缘 56px 宽 × 全屏高，可视细条仅 8px）。悬停展开全部在 webview 内部用 CSS/spring 完成——避免 Win32 窗口 resize 抖动；透明区域照样接收文件拖放，还扩大了命中区。
- **panel 显隐不抢焦点**：Rust 侧 `win.rs` 用 raw window handle 调 `ShowWindow(SW_SHOWNOACTIVATE)`；bar 与 panel 之间用 mouseenter/leave + 150ms 延迟保持连续悬停区。
- 托盘菜单（主菜单入口）：场景切换、显示/隐藏浮条、打开设置、打开暂存文件夹、退出。

## 2. 拖放策略（Windows 实况）
- **拖入（bar 窗口）**：Tauri 原生 drag-drop → 拿到绝对路径（文件/文件夹/多选）。
  - 落下后按设置执行：**每次询问（默认）→ 弹出小菜单「复制 / 移动 / 创建快捷方式 / 取消」+ 记住选择**；设置可固定为复制/移动/快捷方式以跳过询问。
  - 修饰键直达（跳过询问）：Ctrl=复制、Shift=移动、Alt=创建快捷方式（遵循 Windows 惯例）。
  - 重名自动追加「 (2)」；移动失败回退复制并提示。
- **文字拖入**：优先验证 HTML5 drop 透传（text/plain）；若原生 drag-drop 拦截导致不可用，兜底三通道：bar 上 Ctrl+V 粘贴、全局热键「收集剪贴板」、面板「+ 文字」按钮。文字一律存为暂存文件夹内 `.txt` 文件，统一文件模型。
- **拖出（panel 窗口）**：`tauri-plugin-drag`（Windows 上要求该窗口 `dragDropEnabled: false`，与上面一致）。面板提供「拖出模式：复制 / 剪切」切换，同时遵循系统修饰键。若该插件不可用，备选方案为 `windows` crate 自实现 IDropSource。
- **批量导出**：面板选中项 →「复制到… / 移动到…」→ 文件夹选择对话框 → Rust 批量执行，进度与冲突（覆盖/跳过/重命名）处理。

## 3. 数据层（rusqlite bundled + 迁移，便携目录优先）
- 数据目录：exe 旁 `FloePodData/`（可写则用，真正 U 盘便携）；不可写回退 `%APPDATA%\FloePod`。
- 表：`items(id, scene_id, kind[file|folder|text|shortcut], staging_path, original_path, name, ext, size, created_at)`；`scenes(id, name, sort, created_at)`；`settings(key, value JSON)`。
- 快捷方式：Rust COM (IShellLink) 生成 `.lnk`，`kind=shortcut` 记录原路径。
- `notify` crate 监听暂存文件夹，用户在资源管理器手动增删文件时自动对账数据库。
- 场景：同一暂存文件夹内按 `scene_id` 逻辑分组（面板头部 + 托盘切换），默认场景「默认」。

## 4. 设置项（存 SQLite kv）
- 常规：暂存文件夹（选择器 + 打开）、拖入动作（每次询问/复制/移动/快捷方式）、开机自启。
- 外观：形态（浮动条/浮动书签）、屏幕边缘（左/右）、条宽/透明度/材质（Acrylic/Mica/纯半透明）、深浅色跟随系统。
- 交互：悬停展开延迟、点击行为（展开/固定）、面板宽度。
- 快捷键（global-shortcut，可改键）：显示/隐藏浮匣、收集剪贴板文本、打开面板。
- 首次启动：设置窗口引导选暂存文件夹（默认建议「文档\浮匣暂存」）与形态。

## 5. UI/UX 设计（apple-design + kill-ai-slop 落地）
- **材质与层级**：panel 用 Acrylic/Mica（`windowEffects`）+ webview 内 `backdrop-filter` 兜底；更大表面更厚阴影、更重材质；不叠轻玻璃层。
- **动效（motion-v / Motion for Vue）**：spring 参数统一 `damping 1.0 / response 0.3–0.4`；拖入命中时条体「呼吸」确认 + 计数徽标弹性更新；panel 从书签锚点 `transform-origin` 展开、沿来路退出；动画可中断、从当前值起跳；`prefers-reduced-motion` 降级为淡入淡出。
- **反 AI 味**：单一冰蓝强调色（避开默认 indigo/violet 渐变）、无渐变剪裁标题、无 emoji 图标、无发光状态点、无彩色左边框提示框；层级靠字号字重与留白；真实文件类型图标 + 图片缩略图（asset 协议）；克制圆角与阴影；具体直白的中文文案。交付前跑 kill-ai-slop 扫描器并逐条修复。
- 字体：系统字体 + 尺寸相关字距（大标题负字距、小字号微正字距）。

## 6. 代码结构
```
src/                    # Vue 前端
  windows/  Bar.vue / Panel.vue / Settings.vue
  components/  (文件卡片、缩略图、动作菜单、场景切换…)
  stores/    (pinia: items / scenes / settings)
  lib/tauri.ts (invoke 封装 + mock 层供浏览器内 UI 开发)
src-tauri/src/
  lib.rs  commands/ (staging, files, scenes, settings, window)
  db.rs  watcher.rs  win.rs  lnk.rs
```

## 7. 里程碑
1. **M1 脚手架**：create-tauri-app + Tailwind v4 + 多窗口骨架 + bar 两形态切换 + panel 不抢焦点显隐。
2. **M2 暂存核心**：拖入 → 询问菜单/修饰键 → 复制/移动/.lnk → 入库 → panel 列表/缩略图/删除/打开。
3. **M3 导出拖出**：批量复制/移动导出、tauri-plugin-drag 拖出、拖出模式切换、文字暂存三通道。
4. **M4 系统集成**：设置窗口全量、场景、热键、自启、托盘、watcher 对账、首启引导。
5. **M5 设计打磨**：动效精修、kill-ai-slop 扫描修复、深浅色、图标。
6. **M6 交付**：`pnpm tauri build`（x86_64-pc-windows-msvc）→ 取 release exe + 便携数据目录逻辑 + 使用说明 → `FloePod-0.1.0-win-x64-portable.zip`。

## 8. 验证
- `cargo test`：数据库迁移、重名冲突、便携目录判定、路径边界。
- 手动清单：文件/文件夹/图片/多选拖入、三种动作、修饰键、文字拖入/粘贴/热键、拖出复制与剪切、批量导出移动、删除、场景切换、热键、自启、重启持久化、暗色模式、主屏边缘定位。

## 风险与备选
